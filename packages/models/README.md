# @meeting-stt/models

어느 모델을 쓰는지에 대한 **단일 정의**. 파일 다운로드·캐시 조회 같은 런타임 동작은 각 앱에 있다.

| 모듈                          | 무엇                                                                                                                        |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `@meeting-stt/models/desktop` | 데스크탑이 내려받는 자산 — Whisper ggml 선택지(기본/고품질/저사양), VAD·화자 분할·임베딩, 요약 GGUF. URL·sha256·용량·파일명 |
| `@meeting-stt/models/web`     | 브라우저가 쓰는 Hugging Face 저장소 id와 dtype별 ONNX 파일 이름                                                             |

두 카탈로그를 한 패키지에 두는 이유는 **모델을 바꾸는 결정이 한 곳에서 내려져야** 하기 때문이다.
런타임이 달라 값은 공유하지 않는다 (데스크탑은 로컬 파일, 웹은 저장소 id).
자산 확보·서명·온보딩 절차는 `.claude/skills/meeting-stt-dev/references/distribution.md`.
