# v0.3.0-preview.3

macOS에서 “앱이 손상되었기 때문에 열 수 없습니다”가 표시되던 서명 오류를 수정했습니다. Developer ID 서명과 Apple 공증을 적용했고, 공증 티켓과 Gatekeeper 승인을 확인했습니다.

## 설치

1. `knot-prototype-0.3.0-preview.3-arm64.dmg`를 내려받아 엽니다.
2. 앱을 Applications에 복사합니다. 기존 앱이 있으면 교체합니다.
3. 앱을 열고 GitHub에 로그인합니다.

macOS 14 이상 Apple Silicon Mac을 지원합니다. 앱을 교체해도 별도로 보관된 앱 데이터는 삭제하지 않습니다. 공유 서버 연결 버전이므로 로컬 Docker 백엔드는 필요하지 않습니다.

## 수정과 검증

- Developer ID로 앱과 포함된 코드를 서명하고 Apple 공증을 받았습니다.
- `codesign --verify --deep --strict`, `stapler validate`, Gatekeeper 검사를 통과했습니다. DMG에도 서명과 공증을 적용하고, 마운트한 DMG 내부 앱을 다시 검사했습니다.
- 서명된 Electron에서 네이티브 SQLite 실행과 운영 API 연결을 확인했습니다.
- 배포 명령에 서명·공증 검사를 추가했습니다. 검사에 실패하면 파일을 게시하지 않습니다.

실제 GitHub 로그인부터 녹음·전사·AI 정리 저장까지의 전체 사용자 흐름과 대용량 녹음 업로드는 별도 점검이 필요합니다. 자동 업데이트는 비활성화돼 있습니다.

## 데이터 보관

이 검증 환경의 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 테스트 회의만 사용하세요. DB 백업과 인증 비밀값은 공개 저장소에 두지 않습니다. DB 백업은 매일 한국 시간 오전 3시에 EC2 내부에 저장하며, 원격 백업은 아직 없습니다.

## 다운로드 검증

DMG와 `SHA256SUMS`를 같은 폴더에 내려받은 뒤 실행합니다.

```bash
shasum -a 256 -c SHA256SUMS
```
