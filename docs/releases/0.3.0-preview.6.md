# v0.3.0-preview.6

회의 전체 정리가 지나치게 짧던 문제를 보완했습니다. 핵심 요약 한 문장은 먼저 보여주되, 본문은 회의 내용과 중요도에 맞춰 자연스러운 글로 작성합니다. 문단 수와 문장 수를 고정하지 않습니다.

새 녹음의 정리는 전사 원문을 우선 읽습니다. 긴 회의는 전사 구간의 메모를 합쳐 전체 흐름을 정리합니다. **정리** 탭의 **전사에서 다시 정리하기**를 누르면 기존 녹음도 새 방식으로 정리할 수 있습니다. 이전 정리본은 로컬 DB와 서버에 산출물로 남고, 화면에는 최신 정리본이 표시됩니다. 주제별 결정·미결정 문서는 다시 분석하거나 변경하지 않습니다.

preview.5 사용자는 앱의 업데이트 안내 또는 **설정 → 업데이트 → 지금 확인**에서 새 버전을 받아 설치할 수 있습니다. 녹음이나 AI 처리가 진행 중이면 작업이 끝난 뒤 설치하세요. macOS 14 이상 Apple Silicon Mac을 지원합니다.

자동 테스트, 타입 검사, 린트를 통과했습니다. AI 글의 품질은 전사 정확도와 사용자가 선택한 모델에 따라 달라지므로 실제 회의에서 확인이 필요합니다.
