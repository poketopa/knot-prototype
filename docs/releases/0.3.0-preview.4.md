# v0.3.0-preview.4

Codex CLI가 설치되어 있고 로그인도 되어 있는데 앱에서 연결을 차단하던 오류를 수정했습니다. CLI 기능 목록의 `under development` 상태를 잘못 해석하던 문제였습니다.

## 설치와 연결

1. `knot-prototype-0.3.0-preview.4-arm64.dmg`를 열고 앱을 Applications에 복사합니다. 기존 앱은 교체합니다.
2. 설정의 AI 정리에서 **Codex CLI (사용자 계정)**를 선택합니다.
3. **연결 확인**을 눌러 응답을 확인합니다. CLI에 로그인하지 않았다면 터미널에서 `codex login`을 먼저 실행합니다.

macOS 14 이상 Apple Silicon Mac을 지원합니다. 운영 API에 연결하므로 로컬 Docker 백엔드는 필요하지 않습니다. 앱 교체 시 기존 녹음과 앱 데이터는 유지됩니다. 자동 업데이트는 꺼져 있으므로 설치 파일로 업데이트하세요.

## 수정과 검증

- 기능 이름과 비활성화 값은 같은 줄에서 확인하고, 중간 상태값에는 공백을 허용합니다. 필요한 기능이 켜져 있거나 누락된 경우는 계속 차단합니다.
- 회귀 테스트 10개와 전체 자동 테스트 639개, 타입 검사, lint가 통과했습니다. 별도 환경이 필요한 API 테스트 7개는 건너뛰었습니다.
- Codex CLI 0.149.1에서 앱과 같은 호출 경로로 합성 연결 확인을 실행해 `OK` 응답을 받았습니다.
- 설치된 preview.4 앱의 설정 화면에서도 `Codex CLI에 연결했습니다 (응답: 확인)`을 확인했습니다.
- 앱과 DMG에 Developer ID 서명과 Apple 공증을 적용했습니다. 공증 티켓과 Gatekeeper 검사, DMG 내부 앱 검증을 통과했습니다.

실제 회의 전체를 Codex로 정리하는 품질·장시간 처리 검증은 별도입니다. 기존 운영 서버와 데이터 구조는 변경하지 않습니다.

## 데이터 보관

Codex를 선택하면 회의 내용이 OpenAI에 전송되며 사용자 계정의 사용량에 포함됩니다. 이 검증 환경의 녹음·전사·AI 정리 파일은 공개 읽기가 가능하므로 공개해도 되는 테스트 회의만 사용하세요. DB 백업과 인증 비밀값은 공개 저장소에 두지 않습니다.

## 다운로드 검증

DMG와 `SHA256SUMS`를 같은 폴더에 내려받아 실행합니다.

```bash
shasum -a 256 -c SHA256SUMS
```
