# v0.3.0-preview.9

문서 사이드바와 본문을 Figma의 **문서/녹음 직후 · 사이드바 열림** 화면에 맞췄습니다. 둥근 흰색 사이드바 안에서 도메인을 펼치고 문서를 선택합니다. 문서를 바꿀 때 사이드바와 스크롤 위치를 유지합니다.

문서·AI·개발·탐색·독서처럼 넓은 도메인으로 문서를 묶습니다. 핵심과 상세를 두 영역으로 나누던 표시를 없애고, AI가 회의에 맞게 고른 핵심 요약·결정·이유·할 일 등의 제목 아래 내용을 이어서 보여줍니다. 해당 내용이 없는 제목은 강제로 만들지 않습니다. 각 문서의 원문 보기 기능은 유지합니다.

녹음 탭은 녹음 시작 화면을 기본으로 보여줍니다. 녹음 종료 후에는 처리 상태를 표시하고, 서버 보관이 끝나면 녹음 시작 화면으로 돌아갑니다. 저장이 실패하면 재시도 화면을 유지합니다.

기존 문서는 **설정 → 문서 관리 → 기존 문서 다시 정리**로 새 형식으로 분석할 수 있습니다. 현재 로그인 사용자의 이 Mac에 보관된 전사를 현재 AI 설정으로 처리합니다. 이전 녹음·전사·AI 결과·서버 스냅샷은 보존합니다. 로컬 정리가 끝난 뒤 서버 반영은 연결 상태에 따라 이어집니다. 같은 재정리 버전에서 성공한 녹음은 반복 처리하지 않습니다.

preview.5 이상 사용자는 **설정 → 업데이트 → 지금 확인**에서 새 버전을 받고 **다시 시작해 설치**할 수 있습니다. macOS 14 이상 Apple Silicon Mac을 지원합니다.

이 검증 환경의 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 시험 회의만 사용하세요.
