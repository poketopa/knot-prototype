# v0.3.0-preview.11

문서의 최상위 분류를 고정된 키워드로 덮어쓰지 않습니다. AI는 현재 로그인 사용자의 기존 도메인 이름을 참고하고, 의미가 맞으면 같은 이름을 재사용합니다. 맞는 분류가 없으면 여러 회의를 묶을 수 있는 새 도메인을 만듭니다. 문서는 여전히 녹음 하나의 원문만 참조합니다.

기존 문서는 자동으로 다시 분석하지 않습니다. **설정 → 문서 관리 → 기존 문서 다시 정리**를 선택하면 현재 AI 설정으로 새 분류와 문서를 생성합니다. 원본 녹음·전사·이전 AI 결과와 스냅샷은 보존합니다.

Claude Code가 실패하면 로그인 필요, 사용량 제한, 안전 실행 옵션 미지원, 네트워크 오류 등을 구별해 다음 행동을 안내합니다. 구버전 CLI의 안전 옵션을 제거해 실행하지 않습니다. **설정 → AI 모델 → 연결 확인**으로 녹음 전에 연결을 확인하세요.

긴 회의의 구간별 결과가 모델 입력 한도를 넘을 때 이미 분석한 내용을 잘라내지 않고 보존합니다. 이 경우 같은 도메인과 같은 제목의 문서만 연결하고, 이름이 다른 주제는 별도 문서로 남깁니다. 의미가 같은 다른 제목을 연결하는 데에는 한계가 있습니다.

실패한 분석을 다시 시도할 때 같은 전사·모델·프롬프트·분류 목록으로 성공한 구간을 재사용합니다. 변경된 입력이나 검증되지 않은 응답은 재사용하지 않습니다. 이전 전체 회의 정리 경로에서도 긴 메모를 압축하기 전에 중단하던 조건을 수정하고, 크기가 줄지 않는 응답의 반복은 제한했습니다.

preview.5 이상은 **설정 → 업데이트 → 지금 확인 → 다운로드 → 다시 시작해 설치**로 업데이트할 수 있습니다. macOS 14 이상 Apple Silicon Mac을 지원합니다.

업데이트 설치 전에 앱 창의 닫기 동작을 종료 모드로 전환합니다. 창을 숨기는 기존 동작이 업데이트 설치를 막던 문제를 수정했습니다. 이전 버전에서 **다시 시작해 설치**를 눌러도 앱이 계속 실행 중이면 **Cmd+Q**로 앱을 완전히 종료하세요. 내려받은 업데이트가 설치됩니다. 녹음·AI 처리 중에는 설치를 진행하지 않습니다.
