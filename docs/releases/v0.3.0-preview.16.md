# 0.3.0-preview.16

녹음 종료 후 다른 탭에 갔다가 녹음 탭으로 돌아오면 현재 정리 화면을 다시 엽니다. 전사나 AI 정리가 진행 중이면 처리 상태를 보여주고, 정리가 끝났으면 두 결과를 비교해 선택할 수 있습니다.

- 새 녹음 화면의 선택 대기 목록을 아래에 배치해 창 오른쪽에서 잘리던 문제를 수정했습니다.
- `새 녹음`을 누르면 기존 정리와 별도로 녹음을 시작할 수 있습니다. 녹음 중에는 현재 녹음 화면을 우선합니다.

macOS 14 이상 Apple Silicon Mac에서 사용할 수 있습니다. 기존 사용자는 앱에서 업데이트하고, 처음 설치하는 사용자는 아래 DMG를 내려받아 Applications에 복사하세요.
