문서 탭에서 카테고리별 문서 목록을 바로 볼 수 있습니다. 각 행에 제목, 핵심 한 문장, 녹음 날짜와 회의 길이를 표시합니다.

- 상단 버튼으로 어느 탭에서든 문서 사이드바를 열 수 있습니다. 탭을 바꿔도 열린 상태가 유지되고, 문서를 선택하면 본문으로 이동합니다. 상단 문서 버튼이나 본문의 문서 경로를 누르면 목록으로 돌아갑니다.
- 설정의 **문서 분류 → 문서 분류 다시 실행**로 서버에 저장된 내 문서 전체를 큰 도메인에 재배치할 수 있습니다. 선택한 AI가 내용에 맞는 분류를 생성합니다. 제목, 본문, 원문 연결, 이전 결과는 유지됩니다. 기존 문서를 다시 쓰는 ‘문서 다시 정리’와 별도 기능입니다.
- 재분류는 자동 실행하지 않습니다. 다른 Mac에서도 서버를 다시 조회하면 같은 분류가 표시됩니다. 오프라인에서는 마지막으로 받은 분류가 유지됩니다.
- 업데이트가 완료된 버전의 설치·재시작 버튼이 남는 문제를 수정했습니다. 녹음·AI 처리·문서 재분류 중에는 업데이트 설치를 막습니다.

macOS Apple Silicon 전용입니다. 앱 내 업데이트로 설치할 수 있습니다.
