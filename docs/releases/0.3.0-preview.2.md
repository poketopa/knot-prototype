# v0.3.0-preview.2

이 버전은 macOS 앱 서명 오류가 확인됐습니다. 새로 설치하지 말고 수정된 릴리스를 사용하세요. 기존 서버 데이터에는 영향이 없습니다.

공유 API에 연결하는 macOS preview입니다. 앱 사용자에게 로컬 Docker 백엔드나 별도 GitHub OAuth 앱 설정이 필요하지 않습니다.

## 설치와 실행

1. `knot-prototype-0.3.0-preview.2-arm64.dmg`를 내려받아 앱을 Applications에 복사합니다.
2. 앱을 열고 음성 인식 모델과 AI 공급자를 선택합니다.
3. GitHub에 로그인한 뒤 테스트 회의를 녹음합니다.

macOS 14 이상 Apple Silicon Mac을 지원합니다. Developer ID 서명과 Apple 공증이 없어 macOS에서 실행이 차단될 수 있습니다. 자동 업데이트는 비활성화돼 있습니다.

## 저장과 기존 데이터

서버가 녹음 파일, 전사 원본, AI 정리본과 도메인별 결정 문서의 스냅샷을 보관합니다. 기존 로컬 버전의 로그인·녹음 이력은 공유 서버로 자동 이전하지 않습니다. 로컬 버전과 공유 서버 버전은 별도 앱 데이터 폴더를 사용합니다.

이 검증 환경에 업로드하는 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 테스트 회의만 사용하세요. DB 백업과 인증 비밀값은 공개 저장소에 두지 않습니다. 외부 AI 공급자를 선택하면 회의 내용이 해당 공급자에게 전송될 수 있습니다.

## 검증 범위와 제한

- 운영 API의 HTTPS 상태 확인, DB 연결, 인증 없는 요청 차단, OAuth 로그인 시작 요청을 확인했습니다.
- 배포 설정 테스트 31개와 앱 접속 설정 테스트 12개, 전체 타입 검사와 ESLint가 통과했습니다. macOS 빌드 후 패키징된 Electron에서 네이티브 SQLite와 운영 API 연결을 확인했습니다.
- 실제 DB dump와 체크섬 검증, 백업용 systemd 서비스 실행을 확인했습니다. 백업은 매일 한국 시간 오전 3시에 실행합니다.
- DB 백업은 EC2 내부에 보관합니다. 별도 장치에 보관하는 원격 백업은 아직 없습니다.
- 큰 녹음 파일은 앞단 프록시의 업로드 용량 제한을 받을 수 있습니다. 최대 업로드 크기까지의 검증은 완료하지 않았습니다.
- 이번 배포에서 실제 GitHub 로그인부터 녹음·전사·AI 정리 저장까지 전체 사용자 흐름은 아직 검증하지 않았습니다.

## 다운로드 검증

DMG와 `SHA256SUMS`를 같은 폴더에 내려받은 뒤 실행합니다.

```bash
shasum -a 256 -c SHA256SUMS
```
