# v0.3.0-preview.1

`v0.3.0-preview.1`은 로컬 백엔드 preview 릴리스입니다. 공유 서버가 아직 없으므로 앱 사용에는 로컬 Docker 백엔드와 GitHub OAuth 설정이 필요합니다.

## 포함된 내용

- GitHub OAuth 로그인 흐름
- 녹음 파일, 전사 원본, AI 정리본 저장
- 도메인별 결정 문서와 스냅샷 저장
- 로컬 Fastify API와 PostgreSQL compose 스택
- EC2용 compose 예시와 Caddy 설정
- 로컬 DB 백업 스크립트와 systemd timer 템플릿

## 제한

- macOS 14 이상 Apple Silicon Mac 대상입니다.
- Developer ID 서명과 Apple 공증이 없어 macOS에서 실행이 차단될 수 있습니다.
- 공유 API 서버와 원격 백업 자동화가 없습니다.
- S3 어댑터는 포함되어 있지만 실제 AWS 연결은 검증하지 않았습니다.

## 설치와 실행

1. 아래 DMG를 내려받아 앱을 Applications로 복사합니다.
2. [로컬 사용 가이드](https://github.com/poketopa/knot-prototype/blob/v0.3.0-preview.1/docs/usage.md)에 따라 Docker 백엔드와 GitHub OAuth를 설정합니다.
3. 서버를 실행한 상태에서 앱을 열고 STT 모델과 AI 공급자를 선택합니다.

앱 다운로드만으로 공유 서버에 데이터가 저장되는 버전은 아닙니다. 자동 업데이트도 비활성화되어 있습니다.

## 아티팩트 검증

DMG와 `SHA256SUMS`를 같은 폴더에 다운로드한 뒤 실행합니다.

```bash
shasum -a 256 -c SHA256SUMS
```

## 검증 결과

- 전체 workspace 단위 테스트 628개 통과
- 배포 설정 테스트 22개 통과, Linux systemd 검사 1개 제외
- 격리된 PostgreSQL 통합 테스트 6개 통과
- 타입 검사, ESLint, macOS arm64 빌드 통과

GitHub 실제 로그인과 모델 다운로드·녹음의 전체 사용자 흐름은 이번 릴리스 빌드로 재실행하지 않았습니다.
