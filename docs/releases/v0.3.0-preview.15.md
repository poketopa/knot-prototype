# 0.3.0-preview.15

같은 녹음을 두 가지 방식으로 정리하고 더 선호하는 결과를 선택할 수 있습니다.

- 주제별 정리 묶음 두 개를 `정리 1`, `정리 2`로 나란히 보여줍니다. 좌우 순서는 회의마다 무작위로 정하며 다시 열어도 유지합니다.
- 결과 하나와 선택 이유, 회의 종류를 고르면 선택한 정리만 문서로 발행합니다. 미선택 결과도 보관하며 선택 기록을 서버 DB에 남깁니다.
- 한쪽 생성이 실패하면 완료한 결과를 보존하고 실패한 쪽만 재시도합니다. 비교 중 AI나 모델을 바꿨다면 원래 설정에서 재시도해야 합니다.
- AI가 내용 없는 섹션을 빈 목록으로 반환해도 해당 섹션을 생략하고 나머지 정리를 표시합니다. 내용과 발화 근거 검증은 유지합니다.

기존 문서는 유지합니다. 이 기능은 새 녹음부터 적용합니다.

서버는 앱 업데이트 전에 선택 기록 테이블 migration `006_summary_preferences`를 적용합니다. macOS 배포 파일은 Developer ID 서명, Apple 공증 티켓, Gatekeeper 검사를 통과한 후 게시합니다.
