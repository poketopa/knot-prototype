# 0.3.0-preview.14

문서와 원문에 복사 버튼을 추가했습니다.

- 문서 제목과 같은 줄 오른쪽에 복사 버튼을 두었습니다. 제목, 녹음 날짜·길이, 소제목과 목록을 마크다운으로 복사합니다.
- 원문 패널의 녹음 날짜·길이 줄 오른쪽에 복사 버튼을 두었습니다. 날짜·길이 한 줄 다음에 `[00:15] 참여자 1: 발화` 형식으로 전체 원문을 복사합니다. 발화가 없으면 버튼을 표시하지 않습니다.
- 복사하면 버튼이 2초 동안 `복사됨`으로 바뀌고, 기존 `copied` 이벤트로 기록합니다.
- 버튼은 Figma 문서/원문 열림의 Button/CTA/S를 기준으로 한 단계 작게 적용했습니다: 높이 32px, Pretendard 14px·600.

검증: 데스크톱 테스트 558개 통과, workspace 타입 검사·lint 통과. 서버 변경은 없습니다.
