# v0.3.0-preview.7

회의 전체 정리가 짧은 몇 문장으로 끝나던 문제를 개선했습니다. **정리** 탭에서 핵심 요약 뒤에 회의에서 실제로 다룬 주요 논의를 소제목과 문단으로 읽을 수 있습니다. 논의가 많으면 배경·대안·판단 이유와 이번 회의에서 합의한 범위를 충분히 설명하고, 짧은 회의는 그만큼 간결하게 정리합니다.

정리에는 녹음에서 나온 내용만 사용합니다. 회의가 끝난 뒤 알게 된 구현 현황은 회의 당시 합의처럼 추가하지 않습니다. 추측과 확정된 범위를 구별하며, 주제별 결정·미결정 문서는 기존 **문서** 탭에서 계속 관리합니다.

기존 회의는 **정리 → 전사에서 다시 정리하기**로 새 형식의 정리본을 만들 수 있습니다. 이전 정리본은 로컬 DB와 서버에 보존하고 화면에는 최신본을 표시합니다. 새 형식은 핵심 요약과 소제목·문단·간단한 목록을 읽기 쉽게 표시하며, 이전 형식의 정리본도 계속 읽을 수 있습니다.

preview.5 이상은 **설정 → 업데이트 → 지금 확인**에서 이 버전을 받을 수 있습니다. 녹음이나 AI 처리가 진행 중이면 끝난 뒤 **다시 시작해 설치**를 누르세요. preview.4 이하는 설치 파일을 한 번 직접 받아 교체해야 합니다. macOS 14 이상 Apple Silicon Mac을 지원합니다.

데스크톱 자동 테스트, 타입 검사와 lint를 통과했습니다. 제공된 약 35분 회의 전사로 Codex CLI 생성 결과를 확인했고, 짧은 합성 회의로 로컬 모델의 새 형식 출력을 확인했습니다. 전사 오류가 있는 구간과 모델별 글 품질은 실제 회의에서 계속 확인해야 합니다.

이 검증 환경의 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 시험 회의만 사용하세요.
