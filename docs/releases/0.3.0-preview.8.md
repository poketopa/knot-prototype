# v0.3.0-preview.8

문서 탐색과 녹음 흐름을 **문서 → 녹음 → 설정** 세 탭으로 줄였습니다. 녹음 후 전사·AI 처리·서버 보관 상태는 녹음 탭에서 확인합니다. 처리 화면의 **새 녹음**으로 다음 녹음을 시작할 수 있습니다. 이전 녹음 목록과 별도 정리 탭은 제공하지 않습니다.

한 회의에서 나온 주제마다 새 문서를 만듭니다. 문서 사이드바의 **도메인 → 문서** 트리에서 찾아볼 수 있고, 각 문서는 하나의 회의 전사만 참조합니다. 다른 회의의 같은 주제는 같은 도메인 아래 별도 문서로 표시됩니다. 문서는 읽기 전용입니다.

고정된 결정·미결정 템플릿을 없앴습니다. AI가 주제에 맞는 제목을 골라 상단에 간결한 핵심을 쓰고, 하단 **논의 상세**에 배경·대안·이유·불확실성 등 실제로 논의한 내용을 목록으로 설명합니다. 결정이 없는 일상 대화나 정보 공유도 의미가 있으면 문서로 만듭니다. 정리할 내용이 없으면 빈 상태를 보여줍니다.

기존 누적 문서는 회의별 문서로 분리해 표시합니다. 기존 원본과 이전 스냅샷은 그대로 보관하며, 과거 문서 내용은 AI를 다시 실행하지 않고 옮깁니다. 새 문서는 로컬 AI 처리가 끝나면 서버 보관을 기다리는 동안에도 읽을 수 있습니다.

preview.5 이상은 **설정 → 업데이트 → 지금 확인**에서 새 버전을 받고 **다시 시작해 설치**할 수 있습니다. preview.4 이하는 설치 파일로 한 번 교체해야 합니다. macOS 14 이상 Apple Silicon Mac을 지원합니다.

자동 테스트·타입 검사·lint, 별도 PostgreSQL에서 문서 분리와 원문 연결·중복 발행·사용자 격리를 검증했습니다. 제공된 회의 전사는 실제 Codex CLI로, 결정 없는 합성 대화는 로컬 모델로 새 형식 출력을 확인했습니다. 모델이 작성한 글의 정확성과 전사 품질은 실제 회의 원문과 함께 확인해 주세요.

이 검증 환경의 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 시험 회의만 사용하세요.
