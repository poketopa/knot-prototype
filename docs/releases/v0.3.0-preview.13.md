# 0.3.0-preview.13

문서 목록 글꼴과 작은 창의 사이드바 배치를 수정했습니다.

- Figma 문서 목록/기본의 Pretendard 기준 적용: 제목 16px·600, 요약 16px·400, 페이지 제목 26px·600.
- 문서 목록과 본문이 열린 사이드바를 제외한 공간에 맞춰 줄어들고 좌우 여백을 유지합니다.
- 본문과 원문 패널 사이에 최소 32px 간격을 확보했습니다.
- 공간이 부족하면 원문 패널이 본문 아래로 배치되며, 본문을 덮는 고정 오버레이와 바깥 사각형 공백을 제거했습니다.
- 작은 창에서도 문서 사이드바의 너비와 닫힘 상태를 유지합니다.

검증: 문서 목록/본문 테스트 10개 통과, 웹 타입 검사 통과. 실제 렌더러에서 1040·1280·1440·1800px 창의 가로 넘침과 패널 간격을 확인했습니다.
