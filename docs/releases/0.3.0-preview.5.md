# v0.3.0-preview.5

긴 녹음의 처리 실패를 줄이고, 회의별 전체 정리와 앱 안에서 받는 업데이트를 추가했습니다.

## 설치와 업데이트

macOS 14 이상 Apple Silicon Mac을 지원합니다. **preview.4 이하에서 preview.5로 갈 때는 DMG를 한 번 내려받아 기존 앱을 교체해야 합니다.** 이전 버전에는 앱 내 업데이트가 꺼져 있습니다. 기존 녹음과 앱 데이터는 앱 교체 후에도 유지됩니다.

preview.5부터는 앱을 열 때 새 버전을 확인합니다. 새 버전이 있으면 앱의 안내에서 **받기 → 다시 시작해 설치**를 누릅니다. 설정에서도 **지금 확인**을 누를 수 있습니다. 녹음이나 AI 처리가 진행 중이면 설치를 시작하지 않으며, 내려받은 업데이트는 유지됩니다.

## 변경 사항

- **정리** 탭에서 녹음 하나당 핵심 요약 한 문장과 회의 전체를 짧게 정리한 글을 봅니다. 결정·미결정 사항은 기존 **문서** 탭에서 계속 확인합니다. 이전 녹음은 저장된 AI 분석을 활용하며, 분석이 비었거나 실패했으면 해당 상태를 표시합니다.
- 큰 WAV 파일을 작은 조각으로 나눠 서버에 보내고, 전송이 끊기면 완료된 조각부터 이어서 보냅니다. 긴 전사에 대한 AI 분석도 입력을 나눠 처리합니다.
- 실패한 단계만 다시 시도하고, 이미 실행 중인 전사·AI 작업을 중복 실행하지 않도록 보완했습니다.
- 녹음 경과 시간과 실제 저장된 음성 길이가 크게 다르면 경고를 표시합니다. 이 경고는 누락된 음성을 복구했다는 뜻이 아닙니다.

## 검증 범위

전체 자동 테스트, 타입 검사, 린트와 별도 PostgreSQL에서의 API 통합 테스트를 통과했습니다. 분할 업로드와 재시도, 긴 AI 입력, 빈 정리·실패 상태, 업데이트 동작을 자동 테스트로 확인했습니다.

다른 사용자의 Mac에 있는 2시간 30분 녹음 원본은 직접 확인하지 못했습니다. 따라서 기존 파일의 끝부분이 실제로 누락됐는지, 복구할 수 있는지는 이 릴리스에서 확인하지 못했습니다. 긴 녹음의 실제 환경 재검증도 필요합니다.

이 검증 환경에 업로드한 녹음·전사·AI 정리 파일은 공개 읽기가 가능합니다. 공개해도 되는 테스트 회의만 사용하세요.
