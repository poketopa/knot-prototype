# preview.10 구현 및 검증 계획

목표는 사용자별 큰 도메인으로 문서를 탐색하고, Claude 실행 및 긴 회의 처리 실패에서 원인을 안내하며 보관된 데이터를 재사용하는 것이다.

1. 고정 도메인 키워드 분류를 제거하고 사용자의 기존 도메인을 참고하는 AI 프롬프트로 교체한다. 다른 사용자의 도메인은 제공하지 않는다.
2. Claude 실패를 로그인·사용량·옵션 호환성·네트워크 등으로 구분한다. 안전 옵션과 원본 진단 파일은 유지한다.
3. 긴 구간 응답이 입력을 초과하면 내용을 보존해 같은 도메인·제목만 연결한다. 기존 전체 회의 정리 경로의 성급한 중단 조건을 수정하고 진행이 없는 반복을 제한한다.
4. 검증 가능한 성공 구간을 같은 입력의 재시도에서 재사용한다. 전사·분류 목록·모델·프롬프트가 변경되면 다시 분석한다.
5. 분류 보존, 큰 구간 결과, 누락 감지, 재시도, CLI 오류 안내를 테스트한다. 실제 CLI 호출과 타입·린트·빌드 검증을 수행한다.
6. 공개 파일과 작업 단위 커밋을 확인하고, 서명·공증·Gatekeeper 검증을 통과한 앱만 릴리즈한다. 서버 변경이 없으면 정상 동작 중인 API를 교체하지 않는다.

기존 문서 재분석은 설정의 명시적 실행으로 적용한다. 자동으로 다른 사용자의 AI를 실행하거나 기존 결과를 삭제하지 않는다. 다른 Mac의 exit_1 원인은 해당 기기의 로그와 재시험 전에는 확정할 수 없다.

실제 앱 내 업데이트 검증에서 기존 창 숨김 동작이 설치 종료를 막는 문제를 확인했다. 설치 전에 종료 모드를 지정하는 수정과 회귀 테스트를 추가하고, 최종 배포 버전을 preview.11로 변경한다. preview.10은 공개 배포 목록에서 제외한다.
