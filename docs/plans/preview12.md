# preview.12 구현·검증 계획

문서 메인은 카테고리별 목록으로 표시하고 사이드바는 모든 탭에서 독립적으로 열고 닫습니다. 기존 데이터의 재분류는 서버에 저장된 현재 사용자 문서 전체를 대상으로 하며 제목·본문·원문 연결을 변경하지 않습니다.

1. Figma의 User Flow · 화면 흐름 / 아카이빙 · 문서의 목록·상세·사이드바·원문 구조를 확인합니다. 기존 문서·녹음·설정 메뉴를 유지하고 참석자·문서 확인자·플로팅 기능은 추가하지 않습니다.
2. 서버에 분류 입력 조회와 전체 분류 변경 API를 추가합니다. 사용자 격리, 전체 문서 ID 일치, 낙관적 충돌 검사, 트랜잭션과 요청 중복 방지, 이전 분류 이력을 검증합니다.
3. 사용자 선택 AI로 문서 제목·핵심·본문 맥락에서 넓은 도메인을 생성합니다. 분석 중 기존 데이터는 그대로 표시하고 전 문서 검증 후 서버에 한 번에 반영합니다. 실패 시 원본을 유지하며 네트워크 응답 유실은 같은 요청으로 다시 확인합니다.
4. 설정에 문서 분류 다시 정리 안내·버튼을 추가합니다. 본문을 다시 쓰는 기존 문서 재정리와 구분합니다. 다른 Mac은 서버 조회 시 같은 분류를 받으며 오프라인 캐시에는 최신으로 받은 분류를 보존합니다.
5. 문서 목록과 사이드바는 같은 도메인을 사용하고 최근 녹음순으로 정렬합니다. 행에는 핵심 한 문장·녹음 날짜·전체 회의 길이를 표시합니다. 상세의 문서 breadcrumb와 상단 문서 탭으로 목록에 돌아옵니다.
6. 업데이트 완료 후 남은 설치 버튼과 재시작 요청을 현재 설치 버전으로 차단합니다. 녹음·AI·재분류 중 설치 가드를 확인합니다.
7. 단위·통합·타입·lint와 실제 앱 화면을 확인하고 원본 보존을 대조합니다. 서버 변경은 백업·마이그레이션·이전 서비스 보존 후 배포하며 앱은 서명·공증·자산 해시 확인 후 Latest로 게시합니다.

기존 사용자 미커밋 meetingSummary.ts 변경은 보존하고 배포 소스에서는 분리합니다. 새로운 의존성은 추가하지 않습니다.
